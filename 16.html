Лекция №7.1

1. Синтаксис transition

Анимация изменений свойств при событиях

        selector {
            transition-property: all | property-name;
            transition-duration: 0.3s;
            transition-timing-function: ease | linear | cubic-bezier();
            transition-delay: 0s;
            /* Сокращённая запись: */
            transition: all 0.3s ease 0.1s;
        }

2. Правило @keyframes

Определение этапов анимации

        @keyframes animation-name {
            from { /* Начальное состояние */ }
            30% { /* Промежуточное состояние */ }
            to { /* Конечное состояние */ }
        }
        .element {
            animation: animation-name 2s ease-in 1s 3 alternate;
        }

Порядок параметров animation: name duration timing-function delay iteration-count direction

3. Функции плавности

Управление скоростью анимации

        transition-timing-function:
            ease (по умолчанию)
            linear (постоянная скорость)
            ease-in (ускорение)
            ease-out (замедление)
            cubic-bezier(0.17, 0.67, 0.83, 0.67)
            steps(5, start) (дискретные шаги)

4. Несколько анимаций

Параллельное выполнение разных анимаций

        .element {
            animation: 
                slide 2s ease,
                fade 1.5s linear;
        }
         
        @keyframes slide {
            from { transform: translateX(-100%); }
        }
        @keyframes fade {
            from { opacity: 0; }
        }

5. Свойство transform

Комбинирование трансформаций

        transform: 
            translateX(50px)    /* Смещение */
            rotate(45deg)       /* Вращение */
            scale(1.2)         /* Масштаб */
            skew(15deg);       /* Наклон */
         
        /* 3D-трансформации */
        transform: perspective(500px) rotateY(30deg);

6. Контроль выполнения

Свойства управления анимацией

        .element {
            animation-play-state: running | paused;
            animation-fill-mode: 
                none | forwards | backwards | both;
        }
         
        /* Пример остановки при наведении */
        .element:hover {
            animation-play-state: paused;
        }

7. Задержки для элементов

Последовательное выполнение для группы

        .item:nth-child(1) { animation-delay: 0s; }
        .item:nth-child(2) { animation-delay: 0.2s; }
        .item:nth-child(3) { animation-delay: 0.4s; }
        .item:nth-child(4) { animation-delay: 0.6s; }
         
        /* Или через CSS-переменные */
        .item { animation-delay: calc(var(--i) * 0.1s); }

1. Вращение элемента

Бесконечная анимация вращения с помощью @keyframes

        .spinner {
            width: 50px;
            height: 50px;
            border: 4px solid #f3f3f3;
            border-top: 4px solid #3498db;
            border-radius: 50%;
            animation: spin 2s linear infinite;
        }
         
        @keyframes spin {
            0% { transform: rotate(0deg); }
            100% { transform: rotate(360deg); }
        }

2. Fade-in эффект

Постепенное появление элемента с задержкой

        .fade-in {
            opacity: 0;
            animation: fadeIn 1.5s ease-out forwards;
            animation-delay: 0.5s;
        }
         
        @keyframes fadeIn {
            from { opacity: 0; transform: translateY(20px); }
            to { opacity: 1; transform: translateY(0); }
        }

Сочетание нескольких трансформаций

5. Пошаговая анимация

Имитация спрайтовой анимации с помощью steps()

            width: 100px;
            height: 100px;
            background: url('sprite-sheet.png') 0 0;
            animation: play 1s steps(6) infinite;

        }

3. Timeline

Последовательность анимаций:

            duration: 500

        });

5. Stagger

Каскадная анимация:

        anime({
            targets: '.item',
            scale: 1.2,
            delay: anime.stagger(100),
            duration: 500
        });

6. Ключевые параметры

Важные настройки:

        anime({
            loop: 3,          // Кол-во повторов
            direction: 'alternate',
            autoplay: false  // Ручной старт
        });

7. Анимация по пути SVG

Движение объекта вдоль SVG-пути:

        <svg width="200" height="200">
            <path id="motion-path" d="M10 80 Q 100 10 190 80" fill="none" stroke="grey"/>
            <circle id="mover" cx="0" cy="0" r="5" fill="red"/>
        </svg>
         
        anime({
            targets: '#mover',
            translateX: anime.path('#motion-path')('x'),
            translateY: anime.path('#motion-path')('y'),
            duration: 3000,
            loop: true
        });

12. Анимация текстового контента

Посимвольное появление текста:

        const textElement = document.querySelector('.text-anim');
        textElement.innerHTML = textElement.textContent
            .split('')
            .map((char, i) => `<span style="opacity:0">${char}</span>`)
            .join('');
         
        anime({
            targets: '.text-anim span',
            opacity: [0, 1],
            delay: anime.stagger(50),
            duration: 500
        });

13. Индикатор загрузки

Анимированный прогресс-бар с цифровым отображением %

        <div class="loader-container">
            <div class="loader-bar"></div>
            <div class="loader-text">0%</div>
        </div>
         
        anime({
            targets: '.loader-bar',
            width: '100%',
            duration: 3000,
            easing: 'easeInOutQuad',
            update: function(anim) {
                document.querySelector('.loader-text').textContent = 
                    Math.round(anim.progress) + '%';
            }
        });

19. Анимация карточек

3D-эффект наклона карточки при наведении курсора

        document.querySelectorAll('.card').forEach(card => {
            card.addEventListener('mousemove', (e) => {
                const x = e.clientX - card.offsetLeft;
                anime({
                    targets: card,
                    rotateY: (x / 20) + 'deg',
                    duration: 150
                });
            });
        });
